# マーケット指標 (Web版 / PWA)

Mac不要・Apple ID不要・スマホだけで動かせる、経済指標表示アプリのWeb版です。

- **USD/JPY**: [Frankfurter API](https://www.frankfurter.app/)からリアルタイム取得
- **日本国債30年金利**: 財務省公表データ(`market-data.json`経由、日次更新)
- **米国失業率**: 米国労働統計局(BLS)公表データ(`market-data.json`経由、月次更新)
- **日本国債30年(ドル建て)**: 財務省(JGB30年利回り)・Frankfurter API(USD/JPY)から取得し、
  DCFモデルでJPY建て理論価格・修正デュレーションを算出した上でUSD/JPYレートを用いて
  米ドル換算価値(額面1万円あたり)を算出(`market-data.json`経由、日次更新)
- **明日の価格予測(AI分析)**: 入札結果・財政/金融政策を巡る不透明感・FRB要人発言などを
  JGB利回り変化とUSD/JPY変化それぞれについてベイズ統計で統合し、インプライドボラティリティ
  (IV)レジームで不確実性を調整した上で、実測相関を用いたモンテカルロシミュレーションで
  米ドル換算価値の予測分布を算出。定性情報の解釈が必要なため自動更新ではなく、分析セッション
  ごとに手動更新するスナップショットです。
- **インプライドボラティリティ(IV)の反映**: JGB・USD/JPY固有のオプションIV(CME CVOL、
  CBOE JYVIX等)は無料で継続取得できるAPIが存在しないため、金利IVの代理指標として
  [ICE BofA MOVE指数](https://www.ice.com/)(米国債オプションIV)、為替IVの代理指標として
  [CBOE VIX指数](https://www.cboe.com/)(株式オプションIV)をYahoo Finance経由で取得し、
  各指数の「現在値 ÷ 直近1年平均」のレジーム比を実測(ヒストリカル)ボラティリティに
  `regime_ratio^0.5` で反映しています(自動計算の統計的レンジ・手動分析のモンテカルロ両方に適用)。
- **現在価値推定モデルへのIV反映(コンベクシティ補正)**: 単純なDCF価格は「今日の利回り・
  為替」を代入した決定論的な値だが、価格は利回りに対して凸(コンベックス)、USD換算は
  為替に対しても凸なため、ボラティリティが大きいほど期待値は単純DCF価格からズレる
  (イェンセンの不等式)。USD建て価値 `g(利回り, 為替) = JPY建て価格 / 為替` を2次のテイラー
  展開し、IVレジーム反映済みのボラティリティと実測相関を用いて
  `usd_value_iv_adjusted`(コンベクシティ補正込みの現在価値推定)を算出し、単純DCF値
  (`usd_value_per_10k_face`)と並べて表示しています。
- **時間発展する確率分布の可視化(自由回転3D)**: 予測モデルが仮定する自由度5のt分布について、
  時間軸(現在→7/4→7/6)を奥行きとして追加したリッジラインプロットを、外部の3Dライブラリを
  使わずSVG上で幾何学的に描画しています。密度を高さと色(青→緑→黄→赤)の両方で表現し、
  時間が進むほど分布の裾が広がる(不確実性が増す)様子を可視化。ドラッグ/スワイプ操作で
  トラックボール風に方位角・仰角を自由に変更できる汎用3D回転(正投影+ペインターズアルゴリズムに
  よる隠面処理)を実装しており、どの角度から見てもチャート全体が枠内に収まるよう、
  回転のたびに投影後の外接矩形を計算してスケール・中心位置を自動調整しています。
- **GARCH(1,1)-tによるボラティリティ・クラスタリングの反映**: 過去60営業日の等ウェイト標準偏差は
  「窓内一律・窓外は無視」という単純な推定だが、実際の金融時系列は「荒れた相場の後は荒れが
  続きやすい」性質(ボラティリティ・クラスタリング)を持つ。そこで
  `σ²_t = ω + α・r²_{t-1} + β・σ²_{t-1}` というGARCH(1,1)モデルを、JGB利回り変化・USD/JPY
  変化・USD建て価値そのもの、それぞれ直近最大750営業日の系列に当てはめ、Engle–Mezrich(1996)の
  分散ターゲティング法(`ω = 長期分散・(1-α-β)`と置きパラメータ探索を`(α, β)`の2次元に削減)で、
  格子探索+局所精緻化による最尤推定(追加ライブラリ不要)を実施。従来は正規分布を仮定した尤度関数を
  用いていましたが、金融リターンの過剰尖度をボラティリティ推定自体にも反映するため、
  Bollerslev(1987)のGARCH-tモデルに近い**反復プロファイル尤度**方式(①正規尤度でGARCHを粗く
  推定→②標準化残差にt分布をMLEであてはめ自由度νを推定→③そのνでt分布尤度によりGARCHを
  再推定、を収束するまで数回繰り返す)に変更しています。得られた翌営業日の予測ボラティリティ
  (`garch11.forecast_vol`)と、IVレジーム反映後の実測ボラティリティとの幾何平均を最終的な
  採用ボラティリティとして、統計的レンジ・現在価値推定のコンベクシティ補正・手動分析の
  モンテカルロすべてに反映しています。
- **自由度ν(裾の厚さ)のデータ駆動推定**: これまで「自由度5」を固定値として仮定していましたが、
  実際の裾の厚さは市場ごとに異なります。GARCH標準化残差(ボラティリティ・クラスタリングを
  除去した「純粋なショック」)にロケーション0のt分布を格子探索+局所精緻化によるMLEであてはめ、
  自由度ν(`degrees_of_freedom.estimated_nu`)を市場データから直接推定しています。汎用的な
  t分布のCDF・分位点関数は、正則不完全ベータ関数をNumerical Recipes方式の連分数展開
  (Lentzのアルゴリズム)で計算し、そこから導出した厳密解を二分探索で数値的に逆関数化することで、
  任意のνに対応できるようにしています(追加ライブラリ不要)。
- **極値理論(EVT: Peak-Over-Threshold + 一般化パレート分布)**: t分布による近似は「分布全体」の
  形状を単一のνで表現しますが、Pickands–Balkema–de Haanの定理により、十分高い閾値を超えた
  超過量の分布は(元の分布によらず漸近的に)一般化パレート分布(GPD)に従うことが知られています。
  過去のUSD建て価値の日次変化率(上位10%点を閾値)に直接GPDをMLEであてはめ(`evt_tail_risk`)、
  裾そのものを直接モデル化したVaR・ESをクロスチェックとして算出しています。
- **Filtered Historical Simulation(FHS)**: GARCHで標準化した実測残差の経験分布を、正規分布や
  t分布のような分布形状の仮定を一切置かずにそのまま使い、翌日の予測ボラティリティでスケールして
  ノンパラメトリックにExpected Shortfallを求める手法です(`filtered_historical_simulation`)。
  パラメトリックモデルが見逃しうる、実際のショックの非対称性や特異な分布形状を直接反映できます。
- **Expected Shortfall(CVaR, 95%)のアンサンブル**: VaR(90%区間の下限など、パーセンタイル)は
  「その水準を超える確率」しか示さないが、Expected Shortfallは「その水準を超えて悪化した
  場合の期待値」を示す整合的リスク尺度(coherent risk measure)であり、Basel III/FRTBで
  VaRからESへの移行が進んだ理由でもある。前提の異なる3手法「パラメトリック(データ駆動の
  自由度νのt分布解析解 `ES_α = (g_ν(q_α)/α)・(ν+q_α²)/(ν-1)`)」「EVT(極値理論)」
  「FHS(Filtered Historical Simulation)」をそれぞれ算出し、最も保守的(価格が最も下がる)な
  値を採用したアンサンブルを`expected_shortfall_95`として表示。3手法すべての内訳も
  `expected_shortfall_95.components`として併記しています。
- **バックテスト(ローリングVaR超過率 + Kupiec比率的中検定)**: モデルの妥当性を検証するため、
  過去データに対して直前60営業日の実測ボラティリティから日々VaR(95%)を計算し、実際の
  リターンがそれを下回った(超過した)頻度を測定。期待超過率(5%)と統計的に整合しているかを
  Kupiec(1995)の比率的中検定(尤度比検定)で評価しています(`backtest_var_95`。バーゼル規制の
  VaRモデル検証で標準的に用いられる手法)。
- **テール依存の実測診断(コピュラの簡易代替)**: 線形相関(ピアソン相関)だけでは「同時に
  大きく悪化する」確率を過小評価しうるため、利回り上昇と円安(共にUSD建て価値にとって悪材料)が
  同時に上位10%の極端な水準となる経験的な同時確率を、正規分布(独立)を仮定した場合の理論値と
  比較しています(`yield_fx_tail_dependence`)。超過比が1を大きく上回る場合、線形相関のみを
  用いたモンテカルロがテールシナリオの同時発生確率を過小評価している可能性を示唆します。

`market-data.json` は `scripts/fetch_market_data.py` を GitHub Actions
(`.github/workflows/update-market-data.yml`) で毎日自動実行して更新しています。
財務省・BLSのAPIはブラウザから直接叩くとCORSでブロックされるため、
ビルド時に取得したJSONを同一オリジンの静的ファイルとして配信する方式にしています。

> **注意**: 「明日の価格予測」は教育・分析目的の試験的なモデル出力であり、投資助言ではありません。

## 使い方(iPhoneのみでOK)

1. Safariで公開URLを開く
2. 画面下部の「共有」ボタン(四角に上矢印のアイコン)をタップ
3. 「ホーム画面に追加」を選択
4. ホーム画面にアイコンが追加され、以後はアプリのようにタップで起動可能

ネイティブのiOSアプリ(`ios/USDJPYRate/`)と見た目・機能はほぼ同じです。App Store経由でのインストールではないため審査や証明書は不要です。
