# ドル円レート (Web版 / PWA)

Mac不要・Apple ID不要・スマホだけで動かせる、ドル円レート表示アプリのWeb版です。
[Frankfurter API](https://www.frankfurter.app/)からレートを取得して表示します。

## 使い方(iPhoneのみでOK)

1. Safariで公開URLを開く
2. 画面下部の「共有」ボタン(四角に上矢印のアイコン)をタップ
3. 「ホーム画面に追加」を選択
4. ホーム画面にアイコンが追加され、以後はアプリのようにタップで起動可能

ネイティブのiOSアプリ(`ios/USDJPYRate/`)と見た目・機能はほぼ同じです。App Store経由でのインストールではないため審査や証明書は不要です。
