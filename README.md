# 金ETFポートフォリオ運用支援アプリ

このプロジェクトは、米国市場と日本市場の主要な金ETFの分析、ポートフォリオ最適化、リバランス提案など、包括的なポートフォリオ運用支援を提供します。

## 主な機能

### 1. 金ETF分析
- 標準偏差（ボラティリティ）、リターン、シャープレシオの計算
- リスク・リターン比較

### 2. ポートフォリオ最適化
- 最大シャープレシオポートフォリオの提案
- リスクプロファイル別（保守的・中庸・積極的）の推奨配分
- 効率的フロンティア分析

### 3. ポートフォリオ管理
- 保有銘柄のパフォーマンス追跡
- 評価損益の計算
- リバランス提案

### 4. インタラクティブアプリ
- ETF購入・売却のシミュレーション
- ポートフォリオの保存・読み込み

## 分析内容

過去1年間のデータを基に、以下の指標を計算します：

- 日次標準偏差
- 年率標準偏差（ボラティリティ）
- 年率平均リターン
- 価格レンジ（最低・最高）
- 平均出来高（流動性）

結果は標準偏差が低い順にソートされ、最もボラティリティが低い（リスクが低い）ETFを特定します。

### 📊 個別ETF分析

#### 米国市場
**最も標準偏差が低いETF**: GLDM（年率標準偏差 15.10%）

#### 日本市場
**最も標準偏差が低いETF**: 424A.T（年率標準偏差 14.10%、為替ヘッジあり、信託報酬 0.1775%）

**為替ヘッジなしの場合**: 314A.T、425A.T（年率標準偏差 16.40%）

**シャープレシオ最優秀**: 425A.T（シャープレシオ 1.689）

### 重要な発見
- 日本市場で為替ヘッジありのETFを選ぶと、米国市場より低い標準偏差を実現可能
- **424A.T（グローバルX）**: 最低標準偏差 + 東証最低水準の信託報酬（0.1775%）
- **425A.T（グローバルX）**: 最高シャープレシオ1.689（リスク調整後リターンが最も優秀）
- 為替ヘッジなしの場合、ドル円為替変動により標準偏差が約2.3%増加
- 流動性重視の場合は1540.T（純金上場信託、出来高850,000株/日）が最適
- 2025年に新規上場した424A.T、425A.T、447A.Tは低コストで注目
- **ポートフォリオ分散により、シャープレシオをさらに向上可能**（単一ETFより効率的）

## 包括的分析（標準偏差 + リターン + シャープレシオ）

```bash
python gold_etf_comprehensive_analysis.py
```

### 標準偏差2%の差が意味するリスク

100万円を投資した場合:
- **標準偏差14%**（為替ヘッジあり）: 最悪時の損失 約28万円
- **標準偏差16%**（為替ヘッジなし）: 最悪時の損失 約32万円
- **差**: 約4万円の追加リスク

### リターン分析の重要な発見

**過去1年のパフォーマンス（概算）:**

| カテゴリ | 年率リターン | 年率標準偏差 | シャープレシオ |
|---------|------------|------------|--------------|
| 為替ヘッジあり（424A.T） | 8.5% | 14.1% | 0.567 |
| 為替ヘッジなし（425A.T） | **28.2%** | 16.4% | **1.689** |

**結論:**
- わずか2%の追加リスクで、リターンが約20%増加
- 円安効果により、為替ヘッジなしの方がシャープレシオ3倍優秀
- ただし、円高転換時は為替ヘッジありが有利
